# Bundled fonts

The UI uses the variable versions of **Atkinson Hyperlegible Next** and
**Atkinson Hyperlegible Mono** from the Braille Institute, bundled locally so the
app works offline.

- Next: https://github.com/googlefonts/atkinson-hyperlegible-next
- Mono: https://github.com/googlefonts/atkinson-hyperlegible-next-mono
- Both are licensed under the SIL Open Font License 1.1. See the matching
  `LICENSE-*.txt` files in this directory.

Files come from the Fontsource variable packages (`@fontsource-variable/atkinson-hyperlegible-next`
and `@fontsource-variable/atkinson-hyperlegible-mono`), latin and latin-ext subsets.
