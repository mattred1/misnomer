What do the fields mean?
  • {title} — a short 2 to 5 word description of what the file is
  • {entity} — the vendor, company, or person tied to the document, if any
  • {date} — the document's date, formatted per the Date format option below
  • {type} — the document type, like invoice, receipt, screenshot, or photo
  • Custom fields from Settings are marked with *

Where do I find models?
Find models: huggingface.co vision GGUF models
  1. Install the engine once: brew install llama.cpp
  2. Open the link, pick a model repo, then Files and versions.
  3. Download the main .gguf (a Q4_K_M file is a good start) and the matching mmproj .gguf from the same repo.
  4. Choose both files above. The first run takes a while to load the model.
